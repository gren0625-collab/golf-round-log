# 落下点ノート

ゴルフのラウンド中に、**打った場所**と**球のあった場所**をGPSで記録する1枚のページ。

- ボタンは実質1つ。緑「ここで打った」→ 黄土「球はここやった」の2タップで1本ぶん
- 番手・ホール・打数と、**距離(yd/m)** と **方位角** を一緒に残す
- 記録は端末の中だけに貯まる。どこにも送らん
- 一回開いたら**電波が無くても動く**（Service Worker）
- 書き出しは CSV（コピー / ファイル保存）

## もう1枚：打感ノート（`range.html`）

打ちっぱなし用。**1発1タップ**で「芯 / トップ / ダフリ / チョロ / 天ぷら / その他」を残す。
打球音の時刻は録音から自動で取るので、**タップは数秒ずれてもええ**。
番手は選びっぱなし、球筋は直前の1発に後から足せる（押さんでもええ）。

## 使い方

1. iPhoneのSafariで開く
2. 真ん中の「位置情報をオンにする」を押して、**「Webサイトの使用中は許可」**
3. 上のドットが緑（±8m以内）になったら準備完了
4. 共有 → **ホーム画面に追加** しとくと次から早い
